# Quantum Teleportation via OAT Boundary Entanglement in ⁸⁷Sr
### A Quantum-Classical Hybrid Control Framework for JILA

This repository contains the complete theoretical, computational, and experimental-control
framework for demonstrating quantum teleportation using boundary entanglement generated by
the One-Axis Twisting (OAT) Hamiltonian in ⁸⁷Sr optical lattice experiments at JILA.

**Key result:** F_opt = (2+C)/3 is an *exact identity* for OAT boundary states (proved from
U(1) symmetry), not a pure-state approximation. Quantum advantage (F > 2/3) survives
single-particle dephasing at JILA's measured T₂ = 118 s with 4–29× safety margin for N=2..16.

## Quick Start

### Prerequisites
```bash
pip install -r requirements.txt
# Requires: jax[tpu], qiskit, qiskit-aer, numpy, scipy, pandas, matplotlib
```

### Run the MPS simulation (N=4, exact)
```python
# src/simulation/oat_teleport_v3_tpu.py
python src/simulation/oat_teleport_v3_tpu.py
# Output: results/simulation/oat_teleport_v3_results.json
# Expected: C=0.309, F_opt=0.7696, Tr[Wρ₂]=-0.183 at χt*=1.091
```

### Run the hybrid loop controller (synthetic validation)
```python
from src.controller.jila_tpu_controller import JILATPUController

controller = JILATPUController(N=4, chi_Hz=1.0)
feedback = controller.run_loop(shots_array, tau_array)
# shots_array: (n_tau, n_shots) array of +1/-1 values
# Returns: F_predicted, theta_A, theta_B, Gamma_mb, framework_id
```

### Calibrate framework probes
```bash
python src/experiments/exp_ibm_trotterized_oat.py   # IBM Lindblad probe
python src/experiments/exp_syk_ed_adapter.py         # SYK probe (G_R(t) ED)
python src/experiments/exp_mbl_xxz_adapter.py        # MBL probe (XXZ chain)
```

## The JILA Experiment

**Goal:** Measure Γ_mb (many-body dephasing rate) and identify the dominant decoherence
framework for N=4 ⁸⁷Sr OAT boundary entanglement.

**Protocol:** 5600 shots · 20 time points · 280 shots/point  
**Expected signal:** W(τ) = −0.181 exp(−0.034 τ)  
**Falsifiable prediction:** W(0) ≈ −0.181 at t* = 1.091/χ (checkable in one shot)

**Two outcomes, both scientifically complete:**
- Γ_mb < 0.135 s⁻¹ → quantum advantage confirmed, J_ex < 34 mHz measured
- Γ_mb > 0.135 s⁻¹ → dominant mechanism identified, mitigation protocol follows

## Connection to Bullock et al. (arXiv:2602.06114)

The OAT Hamiltonian is the **adiabatic limit of the Dicke model** realized by the Rey group
in Be⁺ ion crystals (χ = 4g²/|δ|). Our digital twin models their experiment in this limit.
Their two-mode squeezing (2.6 dB below SQL) maps to C ≈ 0.59 and F_opt ≈ 0.73 via our
theorem. We fill three gaps they name in their conclusions:

1. **EPR → teleportation:** Schmidt rotation + exact F=(2+C)/3 proof
2. **TFD fidelity:** null_res = 2|det(M)|/‖M‖² quantifies TFD proximity
3. **Hayden-Preskill decoder:** D-LinOSS SYK output (ω_k, γ_k) parameterizes the decoder
